## 简介

本仓库做为一个深度学习基础知识学习平台，为个人整理的深度学习学习笔记，面向AI入门学习者搭建较为完整的基础知识体系。
因个人认知水平有限，文中难免存在疏漏、表述偏差甚至理论错误，欢迎各位读者通过 Issue 交流讨论、勘误指正。

本站内容仅用于**非商业公益学习交流**，无任何盈利行为。衷心感谢以下各位创作老师的知识分享，本资料的编写参考了诸位的教学内容：

这是一个面向深度学习与大模型的资料站。学习内容覆盖 Python、PyTorch、Neural Network、NLP、CV、Transformer、Agent、Reinforcement Learning 等基础知识。

## 受众人群
1. 零基础入门人工智能、深度学习的在校学生与自学爱好者；
